# Hakdari-Seogi-Taekwondo-Crane-Stance-Scoring-Device
A wearable ESP32 IMU system that scores balance during the Taekwondo Hakdari Seogi (crane stance). It detects wobbles, hops, and touchdowns using IMUs mounted on the dorsum of the foot and pressure sensors underneath the ball of the foot, providing live scoring on your phone.
